# TelescopeMasks.jl

This package contains tools for generating focus masks for telescopes. These include:
  * [Bahtinov masks](https://en.wikipedia.org/wiki/Bahtinov_mask), tri-Bahtinov masks, and
    generalizations of the Bahtinov mask to any desired degree of symmetry.
  * [Carey masks](https://en.wikipedia.org/wiki/Carey_mask)
  * Duncan masks
  * [Hartmann masks](https://en.wikipedia.org/wiki/Hartmann_mask)

This package also serves as a demonstration of
[CliffordNumbers.jl](https://github.com/brainandforce/CliffordNumbers.jl).
